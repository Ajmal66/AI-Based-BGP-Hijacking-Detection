User Guide

1. Supported Dataset Formats

  • Custom CSV Files
  • RIPE RIS Dumps (.gz)
  • RouteViews Dumps (.bz2)

2. Download Sample Dataset

Use the sample CSV to understand the required structure.

Download Sample CSV

3. Download RIPE RIS Data

RIPE RIS archives contain BGP routing information collected from multiple collectors.

For this system, download UPDATE files only. UPDATE files contain BGP announcements and withdrawals required for hijack detection. Full RIB snapshots are not recommended.
RIPE RIS Archive Download June 2026 Updates

4. Download RouteViews Data

RouteViews archives provide historical BGP update messages collected from Internet exchange points worldwide.

For best results, download UPDATE files only. Files are typically provided in .bz2 format and are supported directly by the system.
RouteViews Archive Download June 2026 Updates

5. Required CSV Columns

Custom CSV files must contain the following columns:

  • prefix_length
  • as_path_length
  • unique_as_count
  • is_prepended
  • origin_position
  • is_origin_at_end
  • peer_asn
  • as_path (required for LSTM model)

6. Model Selection

Model Description
Random Forest Fast and suitable for general BGP anomaly detection.
SVM Conservative classifier with slower processing time than other models.
LSTM Sequence-based model that analyzes AS-PATH patterns and provides the highest detection capability.

7. Record Limit Option

The optional record limit allows users to process only the first N records of a dataset.

Example:

  • 1000 = process first 1,000 records
  • 10000 = process first 10,000 records
  • Empty = process all records
Duplicate, malformed, or incomplete routes may be removed during preprocessing. Therefore, the final number analyzed can be lower than the selected limit.

8. Detection Results

After analysis, the system provides:

  • Total routes analyzed
  • Detected hijack routes
  • Normal routes
  • Downloadable CSV file with prediction labels
